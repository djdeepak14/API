# 🐶 Random Dog Image Generator

A simple web application that fetches and displays **random dog images** from the [Dog CEO API](https://dog.ceo/dog-api/).  
Click the "Generate Dog" button to get a new dog image every time!

---

## 🌟 Features

- Fetches random dog images using **JavaScript Fetch API**
- Displays images dynamically on the page
- Responsive and modern design with a gradient background
- Button hover effects for better interactivity
- Easy to extend to other APIs or features
